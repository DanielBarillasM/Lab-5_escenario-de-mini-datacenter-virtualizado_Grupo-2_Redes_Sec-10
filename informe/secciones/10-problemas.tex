\section{Problemas encontrados}

No se reportan problemas de implementación porque la infraestructura física todavía no se ha ejecutado. El equipo mantendrá un registro con fecha, síntoma, causa, solución y evidencia.

Los riesgos identificados durante la preparación son:

\begin{itemize}
  \item Borrar el disco incorrecto al instalar Proxmox.
  \item Bloquear SSH al cambiar el puerto o habilitar UFW.
  \item Exponer MySQL fuera de la red interna.
  \item Aplicar permisos a una ruta equivocada.
  \item Publicar un token DNS o una llave privada.
  \item Elegir una subred que se superponga con la red física.
\end{itemize}
